Hier beantragt ihr für euer Projekt oder eure Diplomarbeit eine virtuelle Maschine (VM)
oder einen LXC-Container in der Proxmox-Umgebung der HTL Leonding.

NOTE: *English speaking students:* read the link:schueler-guide.adoc[English guide] and use the form
link:https://github.com/htl-leo-infra/vm-antraege/issues/new/choose[„Request a VM or LXC for a project (English)"].

== So läuft es

. link:schueler-leitfaden.adoc[*Leitfaden lesen*] — was ihr bekommt, wie ihr den Projektnamen
  wählt und was es mit Ports und DNS auf sich hat.
. link:https://github.com/htl-leo-infra/vm-antraege/issues/new/choose[*Antrag stellen*]
  — ein GitHub-Issue mit dem Formular „VM oder LXC für ein Projekt beantragen".
  Ihr braucht dafür nur ein GitHub-Konto.
. *Freigabe* — zuerst gibt eure betreuende Lehrkraft frei, danach die Abteilung.
. *IP-Adresse* — eure VM bekommt eine IP-Adresse, sie steht danach im Issue.
. *Erstellung* — die VM wird angelegt. Ihr bekommt eine Nachricht im Issue, sobald sie bereit ist.
. *Nutzungsdauer* — die VM läuft nach 1 Jahr ab, eure Lehrkraft kann verlängern.

Den aktuellen Stand seht ihr jederzeit am Label eures Issues:

[cols="1,3",options="header"]
|===
|Label |Bedeutung

|`status: neu` |Antrag eingegangen, wartet auf Freigabe durch die betreuende Lehrkraft
|`status: betreuer-freigegeben` |Von der Lehrkraft freigegeben, wartet auf Freigabe durch die Abteilung
|`status: av-freigegeben` |Freigegeben, wartet auf IP-Adresse
|`status: ip-vergeben` |IP-Adresse vergeben, VM wird angelegt
|`status: erstellt` |VM ist bereit
|`läuft ab` |VM läuft in höchstens 30 Tagen ab — Lehrkraft kann verlängern
|`abgelaufen` |Nutzungsdauer vorbei, VM wird gelöscht
|`ungültig` |Formular fehlerhaft — bitte den Hinweis im Issue lesen und den Antrag korrigieren
|`abgelehnt` |Antrag nicht genehmigt
|===
